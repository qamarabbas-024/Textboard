# Security Specification

Security is a continuous engineering responsibility.

Cover, where relevant:

- threat model
- assets and trust boundaries
- authentication
- authorization
- session security
- secrets
- input validation
- output encoding
- injection
- XSS
- CSRF
- SSRF
- IDOR
- file handling
- upload security
- rate limiting
- abuse prevention
- privacy
- dependency/supply-chain risk
- logging
- backup/recovery
- deployment security

Classify findings: Critical / High / Medium / Low / Informational.

Critical and High findings may block release.
