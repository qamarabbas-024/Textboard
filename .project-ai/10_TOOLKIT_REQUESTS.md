# Toolkit Requests

If an extension or external capability is genuinely needed, request it as a small actionable item rather than a long interruption.

Example:

> Install the browser accessibility extension X. I need it to automate accessibility inspection of rendered pages. After installation I can continue the visual QA loop.

If an API/account is needed, ask the CEO to obtain/connect it only after verifying that a free/student option exists and that the capability materially improves the product.
