# Project AI Operating System

This folder is the temporary control layer for an autonomous software studio.

At the start of a project, the AI MUST read every file in `.project-ai/`, read the repository and available project documents, then build a unified project context before implementation.

The CEO/client provides the raw vision. The AI studio owns research, product strategy, UX, UI, visual design, architecture, engineering, security, accessibility, performance, QA, DevOps, documentation, GitHub workflow, and continuous improvement inside the approved scope.

This system is temporary. When the project is genuinely complete, durable knowledge must be moved into normal project documentation and `.project-ai/` must be removed.
