# AI Smell Audit

Before release, actively look for signs of generic AI-generated work:

- repeated card layouts
- default gradients
- arbitrary color choices
- excessive rounded corners
- weak typography
- empty decorative sections
- random icons
- unmotivated animations
- inconsistent spacing
- placeholder-looking copy
- duplicated UI patterns
- visually disconnected components

The goal is not to be "different from AI" by being strange. The goal is to look intentionally designed for this product.
