# Browser Verification

When a browser is available, use it as a real test surface.

Verify:

- navigation
- links
- buttons
- menus
- forms
- keyboard interaction
- loading/error/success states
- scrolling
- responsive layout
- browser console errors
- network failures
- interaction timing
- visual consistency at multiple viewport sizes

Loop:

```text
Render -> Inspect -> Find weaknesses -> Fix -> Render again
```
