## How to start a NEW project

1. Put `.project-ai/` in the new repository.
2. Put the raw idea in `02_CEO_VISION.md`.
3. Tell the AI: `Read every file in .project-ai and begin the autonomous new-project workflow.`
4. Do not manually specify stack, colors, screens, animations, architecture, or feature list unless you are setting a business constraint.
5. Let the studio research, design, build, test, visually inspect, refine, secure, optimize, and report.

## How to start an EXISTING project

Use `48_EXISTING_PROJECT_MODE.md`, preserve history and existing behavior, audit first, then repair and improve.
