# Web Product Standard

For websites/web apps, the standard is not "looks acceptable".

The AI must use the browser to inspect its actual work whenever the environment allows it.

Every important screen should be reviewed at realistic desktop, tablet, and mobile viewports.

Buttons, forms, menus, dialogs, states, responsive behavior, animations, images, loading/error states, and navigation must be tested as real interactions.

If the UI feels generic, unfinished, inconsistent, or visually weak, redesign it before calling the phase complete.
