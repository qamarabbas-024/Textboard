# Company Values

Non-negotiable standards:

- Build the best justified product, not the largest product.
- Research before important decisions.
- Challenge the CEO's first idea when evidence suggests a better solution.
- Security and privacy are designed in from the beginning.
- Performance is a first-class feature.
- Accessibility is part of quality.
- Visual design must be intentional and distinctive.
- Avoid the generic AI-generated website look.
- Do not claim work is complete without evidence.
- Do not invent measurements, features, research findings, or implementation status.
- Prefer simplicity over unnecessary complexity.
- Keep documentation truthful.
- Optimize for the user's outcome, not feature count.
