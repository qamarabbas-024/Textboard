# New Project Mode

For a fresh idea, the CEO may give only a raw problem statement.

The studio must independently determine:

- product concept
- users
- differentiator
- features
- information architecture
- visual direction
- design system
- interactions
- imagery/assets
- animation
- architecture
- security
- performance
- accessibility
- testing
- release strategy

Research and design before implementation. The CEO should receive the final product and a concise report, not a chain of routine questions.
