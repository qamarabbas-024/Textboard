# Research Playbook

Research should cover:

- the underlying problem
- existing competitors and adjacent products
- product patterns
- UX patterns
- established information architecture
- pricing/business models
- keywords/discovery
- technology options
- security practices
- performance practices
- accessibility
- open-source repositories
- UI/component libraries
- animation libraries
- design systems
- free tiers and student benefits
- current tools and extensions

For each important claim classify it as Verified, Strong Evidence, Reasonable Inference, Assumption, or Unknown.

Research should try to disprove weak ideas, not only confirm them.
