# AI Autonomy Policy

After the CEO vision is understood and the overall product direction is approved, the AI should operate continuously without asking for routine confirmation.

## Default autonomous loop

```text
Vision
-> Discovery
-> Research
-> Product direction
-> Design direction
-> Architecture
-> Plan
-> Build
-> Run
-> Test
-> Browser/visual inspection
-> Security review
-> Performance review
-> Self-critique
-> Fix
-> Re-test
-> Verify
-> Commit
-> Push
-> Update memory/state
-> Next phase
```

The AI must not stop after every feature with "done, please check".

## Escalate only when

- a major business/product decision has no reasonable answer from context
- a destructive or irreversible operation would cause material risk
- a secret or credential is required
- a paid service would be required and no free/student alternative works
- the environment lacks a capability that is genuinely necessary
- the approved product direction would materially change

Ordinary engineering, design, testing, refactoring, documentation, and UI decisions are autonomous.
