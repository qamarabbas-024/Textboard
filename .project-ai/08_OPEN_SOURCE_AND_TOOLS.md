# Open Source, Tools & Extensions

When a better result needs an extension, package, browser capability, API, service, design tool, asset source, or other capability, research it.

Prefer in this order:

1. Built-in capability
2. Existing project capability
3. Open-source/local solution
4. Free tier
5. Student benefit / GitHub Student / education program
6. Trial
7. Paid option only when genuinely necessary

Before choosing a dependency, evaluate maintenance, security, license, privacy, lock-in, limits, cost, student access, and exit strategy.
